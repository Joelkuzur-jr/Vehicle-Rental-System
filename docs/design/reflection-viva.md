# Sprint 3 – Reflection and Viva Answers

## Reflection Questions

1. **Why is system design important before implementation?**  
   It gives the development team a clear blueprint of the modules, database, navigation and workflows. It reduces confusion and costly changes during coding.

2. **What is the purpose of an ERD?**  
   An ERD shows the entities in a system, their important data and the relationships between them.

3. **Why should application navigation be planned before coding?**  
   It helps make the application easy to use and ensures each user role can reach the pages and functions they need.

4. **How does a wireframe help during development?**  
   A wireframe is a simple page sketch that shows where content, buttons, forms and navigation will appear before detailed UI development.

5. **Why should database collections be identified before creating APIs?**  
   It clarifies what data the application stores and how records relate, helping developers design consistent API requests and responses.

## Viva Questions

1. **What is system design?**  
   System design is the process of planning the structure, components, database and interactions of a software application.

2. **What is an ERD?**  
   An Entity Relationship Diagram is a visual representation of database entities and their relationships.

3. **What is the purpose of a wireframe?**  
   It shows the basic layout and arrangement of a page before visual styling and coding.

4. **Why do we design the database before development?**  
   To identify required data, fields and relationships before building application features and APIs.

5. **What is a MongoDB collection?**  
   A collection is a group of MongoDB documents, similar to a table in a relational database.

6. **What is a relationship between entities?**  
   It describes how records in one entity are connected to records in another entity.

7. **What is application navigation?**  
   It is the structure that allows users to move between pages and features.

8. **What is software architecture?**  
   It is the high-level structure of a system and the way its components work together.

9. **Why is documentation important during system design?**  
   It communicates design decisions and gives developers a reference during implementation.

10. **How does proper planning reduce development effort?**  
    It identifies requirements and design issues early, reducing rework and mistakes during coding.
