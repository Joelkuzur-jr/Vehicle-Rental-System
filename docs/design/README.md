# Sprint 3 – System Design & Database Modeling

This folder contains the Sprint 3 design deliverables:
1. Module diagram

Open the `.mmd` files in https://mermaid.live or a Mermaid-compatible editor to view and export the diagrams. Wireframes are low-fidelity layouts focused on page structure and functionality, not visual styling.
