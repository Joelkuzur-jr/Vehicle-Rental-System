# Vehicle Rental System

## Project Description
The Vehicle Rental System is a web-based application developed to manage vehicle rental operations. It allows administrators and rental staff to manage vehicles, customers, rental bookings, vehicle returns and payments through a centralized platform.

Customers can browse available vehicles, request rentals and view their rental history.

## Project Domain
Transportation & Rental Services

## Technology Stack
- MongoDB – Database management
- Express.js – Backend framework
- React.js – Frontend development
- Node.js – Server-side runtime

## Project Modules
1. User Management
2. Vehicle Management
3. Customer Management
4. Rental Management
5. Return Management
6. Payment Management
